# ClinicalFlow

A modular Nextflow DSL2 pipeline for clinical
research data management.

## Objectives

- Clinical data validation
- Data cleaning and standardization
- Pseudonymization
- Clinical dataset integration
- Data quality assessment
- Research-ready dataset generation

## Tools used 

- Nextflow DSL2
- Python
- Pandas
- Git
- Docker

## A note about patient data

This project uses synthetic clinical data only.
No real patient information is included.
